# Certifying an e-variable

Six revealjs slides driven by live [`ripr`](https://github.com/fleverest/ripr)
runs. Two examples, each stated, fitted, then certified:

1. The plurality problem
2. Fitting the projection (plurality)
3. Certifying the fit (plurality)
4. The medial-triangle problem
5. Fitting the projection (medial)
6. Certifying the fit (medial)

View the slides on the [GitHub Pages site](https://fleverest.github.io/ripr-vis).
